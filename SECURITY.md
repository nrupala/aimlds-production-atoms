# Security Policy

## Reporting a vulnerability

Report security issues privately to **info@aimlds.org**. Do not open a
public issue for a vulnerability.

We acknowledge reports within 5 business days and will tell you what we
find and what we are doing about it.

## Supported versions

The current release on the `main` branch is the supported version.
These atoms are small, dependency-free Python modules; the most useful
reports name the atom, the input payload, and the output you observed.
